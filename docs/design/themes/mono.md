# Mono

> `SwiftForgeTheme.mono` · id `"mono"` · Generated by `scripts/theme-design/gen.py` — do not edit by hand.

**Character:** SF Mono everywhere, one phosphor-green accent, hairline boxes, no shadows, 0.75x spacing, short controls with 44-pt hit areas.

Tokens other than color (shape, shadow, typography, density, motion, and component tokens) and the reasons for
them are in the doc comment in `Sources/SwiftForgeUI/Themes/SwiftForgeTheme+Mono.swift`.
